在賽博都市中重塑你的正義

當霓虹燈火在雨後的街道中倒映出破碎的光影，你將意識到這不僅僅是一款遊戲。《賽博之刃》將我們帶入了一個高度發達卻又極度混亂的未來世界。

對於喜歡動作遊戲的青年玩家來說，其自研引擎帶來的 60FPS 滿幀體驗讓每一次揮砍都流暢無比。而對於新入坑的用戶，其直觀的操作系統和無需下載、點擊即玩的特性，極大地降低了進入門檻。
