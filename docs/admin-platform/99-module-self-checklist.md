# 模块开发自查清单

每完成一个后台模块，必须逐项检查：

## 1. 可上线性

- 是否能在真实业务流程中使用，而不是只能演示？
- 是否存在关键动作只有前端、没有后端落地？

## 2. 权限安全

- 是否只靠前端控制权限？
- 后端是否逐接口做角色与数据权限校验？

## 3. 数据越权

- 开发者是否可能读取其他开发者数据？
- 运营是否能在没有授权时执行高风险操作？

## 4. 状态流转

- 是否存在非法状态绕过？
- 是否所有状态转换都由后端控制？

## 5. 幂等与重复提交

- 是否有重复点击创建重复数据问题？
- 是否有重复提审 / 重复审核 / 重复发布问题？

## 6. 异常场景

- 是否处理了空数据、加载中、接口失败、超时、依赖失败？
- 是否有明确错误提示与恢复路径？

## 7. 操作日志

- 敏感操作是否都写日志？
- 日志是否包含操作人、对象、前后值、原因、来源？

## 8. 测试覆盖

- 是否有正常流测试？
- 是否有越权测试？
- 是否有非法状态测试？
- 是否有重复提交测试？

## 9. Demo 风险

- 是否只是页面打开、按钮能点？
- 是否缺少真实后端、数据库、日志、权限、校验支撑？

## 10. 通过标准

以上任一项答案为“否”或“存在风险”，先修复，再进入下一个模块。
