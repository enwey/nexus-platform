# 运营后台与开发者后台模块地图

## 1. 后台定位

### 1.1 运营后台

运营后台是平台总控台，目标不是复用开发者后台的录入流程，而是：

- 管理平台资产状态
- 管理前端可见状态
- 管理审核与发布口径
- 管理推荐与投放秩序
- 管理开发者主体与风险
- 管理配置变更与审计留痕

### 1.2 开发者后台

开发者后台是开发者自助接入与发布后台，目标是：

- 只管理“我的数据”
- 只执行我有权限的提审、上传、资料维护
- 不能越权查看其他开发者资产
- 不能绕过审核直接影响前端呈现

| --- | --- | --- | --- |

| OPS-002 | 游戏治理中心 | 管理平台游戏主数据与前端可流转状态 | P0 |
| OPS-003 | 推荐运营中心 | 管理分类、投放位、推荐内容与生效状态 | P0 |
| OPS-004 | 开发者管理中心 | 管理开发者主体、资质、风险标签 | P1 |
| OPS-005 | 运行时配置中心 | 管理客户端配置、分发策略、推荐池 | P1 |
| OPS-006 | 风险与审计中心 | 管理日志、风控、操作追踪 | P1 |
| OPS-007 | 权限与平台设置中心 | 管理角色、菜单、操作权限 | P1 |

### 2.2 开发者后台模块

| 编号 | 模块 | 目标 | 优先级 |
| --- | --- | --- | --- |
| DEV-001 | 账号与团队中心 | 管理开发者主体、成员、凭证、安全 | P0 |
| DEV-002 | 我的游戏中心 | 管理我的游戏主数据 | P0 |
| DEV-003 | 版本与发布中心 | 管理上传、校验、提审、版本历史 | P0 |

| DEV-005 | 文档与接入中心 | 提供接入、提审、SDK 文档 | P1 |

## 3. 实施顺序

### 第一批：必须先做成生产级

1. OPS-001 审核中心
2. OPS-002 游戏治理中心
3. OPS-003 推荐运营中心
4. DEV-001 账号与团队中心
5. DEV-002 我的游戏中心
6. DEV-003 版本与发布中心

### 第二批：平台化增强

1. OPS-004 开发者管理中心
2. OPS-005 运行时配置中心
3. OPS-006 风险与审计中心
4. OPS-007 权限与平台设置中心
5. DEV-004 数据与反馈中心
6. DEV-005 文档与接入中心

## 4. 平台边界

### 4.1 运营后台边界

- 可以查看全平台数据
- 可以管理审核状态
- 可以管理前端是否展示
- 可以管理推荐与广告位
- 可以执行高风险操作，但必须带权限与日志

### 4.2 开发者后台边界

- 只能查看自己数据
- 只能操作自己游戏
- 不能改审核结果
- 不能直接上线或控制前端展示
- 不能访问其他开发者上传包、版本、日志

## 5. 当前开发门禁

在首批 P0 模块文档未补齐前，不继续新增 Demo 式功能。
