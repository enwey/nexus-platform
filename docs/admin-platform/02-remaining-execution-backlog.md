# 生产级后台剩余执行总任务单

本文档是当前项目后续开发的唯一剩余任务清单。  
目标不是继续堆页面，而是把剩余模块按生产级标准一次次收口，直到可上线验收。

## 1. 执行原则

- 每个任务都必须覆盖：后端校验、权限、状态流转、异常处理、操作日志、空态/错态/加载态
- 每个批次完成后都必须做最小编译 / 构建验证
- 不以“页面能点”为完成标准，以“真实可上线使用”为完成标准
- 开发顺序按“平台主链路优先、再做运营效率、最后做横向收口”

## 2. 当前整体完成度

- 平台主骨架：`已完成`
- 核心治理链路：`大部分已完成`
- 剩余收口项：`约 30%`

## 3. 已完成基线

以下能力已经进入可继续收口阶段，不再算待从零开发：

- 审核中心基础链路、批量审核、任务分配、申诉复审
- 游戏治理中心、单条和批量封控
- 推荐运营中心分类 / 位 / 内容分轨、批量状态、位总开关
- 营销中心启动广告、活动会场、弹窗活动、任务活动、礼包码活动
- 发布中心发布单、排期、回滚单、到期执行
- 风控中心风险事件、处置记录
- 平台设置中心角色权限覆盖、规则模板、通知模板、字典配置
- 开发者后台账号团队、资质、通知、工单、发布健康、审核趋势、驳回原因统计
